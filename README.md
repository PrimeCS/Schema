1. Start Apache and MySQL in the XAMPP Control Panel (make sure its green).
2. Open ''http://localhost/phpmyadmin'', go to the SQL tab, and run ''schema.sql''.
3. Copy the PHP files into ''C:\xampp\htdocs\grocery\''.
4. Open the pages in your browser, for example `http://localhost/grocery/table.php`.

Run ''insert.php'' before ''delete.php'', since delete removes the record that insert adds
